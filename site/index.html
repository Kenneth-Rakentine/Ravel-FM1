RAVEL.

custom firmware for the M-VAVE FM-1

An eight-track groovebox for sound design: tracks that synthesize, strike and play a shared tape, catch what they play, then cut it up and rebuild it.

What it is

  • 8 tracks: synth engines (VA, phase distortion, FM, physical models, formant, particle), struck resonators, and tape playback (MLR, Beads grains, slices).
  • One capture tape that keeps what you played, and tracks that rebuild it.
  • Influence: any track can trigger, modulate, excite, ring, clock or jump another.
  • Two sequencers per track: steps with locks, ratchets and conditions, or a graph with two playheads and moving speed.
  • Shared effects: delay, space, feedback, filter pair and vocoder, plus scenes and an arrangement.

How it connects

Installing on the FM-1

Read this first. Ravel has been built and tested in the emulator and simulator, but not yet on FM-1 hardware. Installing it is at your own risk.

  1. Try Ravel in the emulator first. The firmware runs the same code.
  2. Back up anything on your FM-1 you want to keep (projects, samples) with M-VAVE's own tools.
  3. Download Ravel-FM1.fwsc from the latest release, and check it against SHA256SUMS.txt if you like.
  4. Install it the way you install M-VAVE's own FM-1 firmware updates, using M-VAVE's update tool (see the FM-1 workbench and its instructions).
  5. Keep the FM-1 powered and connected for the whole update. Don't unplug it part way.
  6. To go back, install M-VAVE's official firmware the same way.
